# Update the GitHub Repository

**English** · [简体中文](./UPDATE_GITHUB.zh-CN.md)

Target repository: `https://github.com/WEILaboratory/Virtue-Agent`

1. Download and **extract** the ZIP on your computer.
2. Open the `Virtue-Agent` folder **inside** the extracted archive.
3. In your GitHub repository, choose **Add file → Upload files**.
4. Upload **the contents** of that folder (`README.md`, `README.zh-CN.md`, all paper pages, and the whole `assets/` directory), **not** the ZIP file or another enclosing folder.
5. Confirm the two language versions of every page appear at the repository root, and images remain in `assets/`.
6. Commit with a message such as `Add bilingual Virtue Agent research pages`.
7. Refresh the repository page. GitHub renders **English `README.md` by default**. Use **简体中文** to open the Chinese version. Verify both links on each project page.

Uploading the new files to existing paths should update the existing repository; there is no need to delete and recreate it. For large nested directories, GitHub Desktop can be more reliable than browser drag-and-drop.

This ZIP contains research descriptions and illustrations only, **not source code or datasets**.
